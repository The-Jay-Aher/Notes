# Shared Foundations

These notes support several advanced tracks and should remain canonical rather than being copied into every certification folder.

| Foundation | Entry point | Used by |
| --- | --- | --- |
| Networking | [Networking Fundamentals](networking/INDEX.md) | AWS, Kubernetes, Docker, security, distributed systems, and troubleshooting. |
| Linux and shell | [Bash](linux/Bash.md) | Server administration, CI/CD, containers, cloud CLIs, and operational automation. |
| Note authoring | [Markdown Cheatsheet](tools/Markdown%20Cheatsheet.md) | Consistent repository authoring and revision sheets. |

When a shared foundation grows, give it its own topic folder with an `INDEX.md`, roadmap, deep chapters, labs or examples, failure modes, practice questions, cheatsheet, glossary, and changelog.
